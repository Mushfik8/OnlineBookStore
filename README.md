📚 Online Book Store

A simple and user-friendly online bookstore where users can explore books, search for their favorite titles, and purchase books online.

✨ Features

Browse and search books

Explore book categories

View book details and prices

Add books to cart

User registration and login

🛠️ Technologies

HTML

CSS

JavaScript

🎯 Purpose

This project is developed to practice web development and create a convenient online book-shopping experience.
